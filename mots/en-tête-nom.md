## note

_en-tête_ peut aussi s'écrire _entête_.

## exemples

🇬🇧 | 🇫🇷
---|---
[File **headers** may be used by an operating system to quickly gather information about a file without loading it all into memory.][1]|Les **en-têtes** de fichiers peuvent être utilisés par un système d'exploitation pour rassembler rapidement des informations sur un fichier sans le charger entièrement en mémoire.
[HTTP **headers** let the client and the server pass additional information with an HTTP request or response.][2]|Les **en-têtes** HTTP permettent au client et au serveur de transmettre des informations supplémentaires dans une requête ou une réponse.
An e-mail **header** is made up of various fields, many of which are syntactically optional.|[L'**en-tête** d'un courriel est composé de différents champs dont plusieurs sont syntaxiquement facultatifs.][3]

[1]:https://en.wikipedia.org/wiki/File_format#File_header
[2]:https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers
[3]:https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/2075033/en-tete-de-courriel
